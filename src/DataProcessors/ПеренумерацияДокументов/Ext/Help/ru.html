Обработка предназначена для упорядочивания номеров счетов-фактур по хронологии и настройки отдельной нумерации счетов-фактур на аванс с префиксом «А».

Порядок работы:
 1. Выберите период - табличная часть будет автоматически заполнена счетами-фактурами за указанные даты.
 2. Укажите параметры нумерации:
 • Начальный номер - для счетов-фактур на реализацию.
 • Начальный номер с-ф на аванс - для авансовых счетов-фактур.
 • Добавлять префикс «А» в номер - добавляет префикс к ранее созданным авансовым счетам-фактурам.
 3. Выполните перенумерацию - номера будут восстановлены в строгой хронологии по датам.
Обрабатываемые документы:
 • Счета-фактуры на реализацию.
 • Счета-фактуры на аванс.
Не обрабатываются:
 • Сводные справки.
 • Корректировочные сводные справки (номер при необходимости редактируется вручную).
Особенности применения:
 • Настройка отдельной нумерации не изменяет ранее созданные документы автоматически. Для перенумерации запустите данную обработку.
 • В печатных формах, поле 5б и Книгах покупок/продаж номера отражаются с префиксами.
 Используемые префиксы:
А - аванс, И - исправления, Р - сводные справки, К - корректировочные сводные справки.
Ограничение: обработка доступна только пользователям с полными правами.
