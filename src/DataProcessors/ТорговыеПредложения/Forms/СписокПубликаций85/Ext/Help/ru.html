Действия с публикуемыми торговыми предложениями

На данной форме происходит управление публикацией торговых предложений.

Все действия с добавленными публикуемыми торговыми предложениями выполняются через командную панель строки или контекстное меню.

Добавление

Для добавления торгового предложения в список публикуемых необходимо нажать команду Добавить.

Просмотр ошибок и предупреждений

Если при попытке публикации торгового предложения возникли ошибки или предупреждения, в самой первой колонке списка появится значок наличия ошибок или предупреждений .

Окно просмотра ошибок и предупреждений открывается нажатием на соответствующую иконку строки или через команду Показать ошибки и предупреждения.

Удаление

Для удаления публикации торгового предложения необходимо воспользоваться командой Удалить публикацию. В результате этих действий, у торгового предложения поменяется состояние.

Непосредственное удаление произойдет только после выполнения синхронизации. До выполнения синхронизации удаление можно отменить, нажав соответствующую команду снова. После выполнения синхронизции торговое предложение пропадет из списка.

Отключение

Для отключения публикации торгового предложения в сервисе необходимо воспользоваться командой Отключить публикацию. В результате этих действий, у торгового предложения поменяется состояние.

Непосредственное отключение произойдет только после выполнения синхронизации. До выполнения синхронизации отключение можно отменить, нажав соответствующую команду снова. После выполнения синхронизции торговое предложение останется в списке, но поменяет состояние на "Отключено".

Синхронизация

Доступно два варианта синхронизации публикуемых торговых предложений:

  • Вручную — для этого необходимо воспользоваться командой Синхронизировать. Также можно выделить все/необходимые строки и выполнить синхронизацию пакетом.
  • Автоматически — для этого необходимо установить флаг Автоматическая публикация торговых предложений(внизу формы) и настроить расписание регламентного задания Синхронизация торговых предложений с сервисом 1С:Бизнес-сеть.

Переход к списку товаров

Для перехода к списку товаров торгового предложения необходимо воспользоваться командой Состояние публикации.

Также можно посмотреть состояния публикаций товаров всех торговых предложений из списка. Для этого нужно воспользоваться командой Состояния публикаций в командной панели списка

Получение внешней ссылки

Для открытия формы получения/обновления внешней ссылки торгового предложения, необходимо воспользоваться командой Внешняя ссылка.

Открытие дополнительных настроек

Для открытия формы дополнительных настроек публикации торгового предложения, необходимо нажать на гиперссылку в колонке Уведомление по эл.почте.

Изменение флагов доп.настроек в списке

Имеется возможность регулировать часть флагов из дополнительных настроек непосредственно из списка. Для этого необходимо нажать на флаг в соответствующей колонке в правой области списка.

Состояния публикаций торговых предложений

Легенда возможных состояний публикаций представлена внизу формы.

Текущее состояние для каждой публикации отображается соответствующим кружком в колонке Состояние.

Переход к списку внешних публикаций

Чтобы открыть форму внешних публикаций (сформированных и опубликованных не из этой информационной базы), необходимо воспользоваться командой Внешние публикации в командной панели списка.

Открыть отчет публикуемых товаров

Для открытия отчета публикуемых товаров необходимо воспользоваться командой Публикуемые товары в командной панели формы.

Отправить приглашения покупателям

Для открытия формы отправки приглашений покупателям необходимо воспользоваться командой Пригласить покупателей в командной панели формы..
