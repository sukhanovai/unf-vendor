Регистрация в сервисе 1С:Бизнес-сеть


Первый шаг для публикации торговых предложений. По команде Зарегистрироваться в сервисе 1С:Бизнес-сеть открывается форма регистрации организаций. Если ни одна организация не зарегистрирована, появляется предупреждение — Организации не зарегистрированы.

Подготовка торговых предложений к публикации


По команде Открыть форму списка публикаций торговых предложений открывается форма публикуемых торговых предложений, где можно добавить новые торговые предложения для публикации, указать дополнительную информацию, сопоставить номенклатуру. Если торговые предложения отсуствуют, появляется предпупреждение — Требуется настройка.

Проверка публикуемых товаров торговых предложений


По команде Состояния публикаций открывается список всех публикуемых торговых предложений с детализацией по товарам.

Сопоставление номенклатуры


Для публикации товаров по рубрикам сервиса 1С:Бизнес-сети, необходимо сопоставить номенклатуру с карточками 1С:Номенклатура (при настройке подсистемы в программе) с рубрикатором сервиса. Сопоставление с рубрикатором производится по видам номенклатуры (если учет по видам включен в программе), по иерархии номенклатуры, по номенклатуре.

Видеоинструкция сопоставление номенклатуры в УНФ

Настройка публикации по расписанию


Для автоматической публикации торговых предложений в сервисе необходимо включить флаг Включить автоматическую синхронизацию и настроить расписание операции.

Выполнение публикации


Команда Синхронизировать выполняет выгрузку торговых предложений в сервис. В случае успешного выполнения будет показываться информация Синхронизация выполнена и время выполнения, в случае возникновения ошибок показывается информация об ошибке. Команда доступна, если во всех предыдущих шагах нет ошибок.
