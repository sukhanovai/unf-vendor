Поиск для организации

Расширяет результаты поиска персональными предложениями для выбранной организации. При отсутствии зарегистрированных в 1С:Бизнес-Сеть организациях, данный пункт отсутствует.

Регион поиска

Устанавливает отбор по регионам организаций или региону, указанному вручную.

Валюта

Устанавливает представления цен предложений в указанной валюте.

Навигация по категориям


Устанавливает отбор по категориям рубрикатора. Для установки отбора необходимо выбрать соответствующий элемент дерева категорий. 

После выбора категории поиск выполниться автоматически.

Отборы


Возможно использование дополнительных отборов для фильтрации списка торговых предложений по доступным характеристикам выбранной категории товаров.

При установке значений отбора повторный поиск производится автоматически.

Имеется возможность сбросить все установленные отборы одним действием по соответствующей кнопке в нижней части панели. 

Предварительный просмотр торгового предложения

Изображение и краткая информация карточки торгового предложения, выделенного в списке результатов.

Для просмотра всей информации, открывается карточка торгового предложения по нажатию на изображение или гиперссылку "Подробнее" (также, карточку можно открыть двойным кликом на строку торгового предложения).

Непосредственно в панели предварительного просмотра имеется возможность:

  • Добавить товар в корзину
  • Указать необходимое количество товара (сразу после добавления в корзину) 
  • Установить отбор по поставщику текущего торгового предложния
  • Установить отбор по категории рубрикатора

Краткое представление содержимого корзины

Список торговых предложений, добавленных в корзину. 

В панели краткого представления содержимого корзины имеется возможность:

  • Удалить из списка позицию целиком
  • Изменить количество единиц позиции
  • Очистить содержимое корзины целиком, соответствующей командой в нижней части панели

Список результатов

В списке результатов отображаются найденные торговые предложения, соответствующие параметрам поиска.

Сортировка результатов

Для результатов поиска возможна сортировка по релевантности и по цене (по возрастанию и убыванию).

Добавление в корзину

Добавление в корзину доступно несколькими способами:

  • Из списка результатов поиска

По кнопке командной панели строки или ручным указанием количества в колонке Корзина

  • Из панели предварительного просмотра торгового предложения

С возможностью указать требуемое количество сразу после добавления предложения в корзину

Переход в корзину

Осуществляется по нажатию на соответствующую кнопку внизу правой панели.
