Рабочее место "Выполнение этапов производства"

Описание

Рабочее место позволяет организовать массовое формирование производственных документов на основании заказов покупателей и заказов на производство. Продукция может производиться в несколько этапов, разными датами и, при необходимости, в разных подразделениях.

Порядок этапов для каждой продукции определяется в спецификации заполнением реквизита "Вид производства". Каждый материал или операция привязываются к определённому этапу. При включенной настройке "Этапы могут выполняться разными подразделениями" каждый этап может выполняться в своём подразделении.

Заказы и продукция

В списке отображаются все незакрытые заказы покупателей и заказы на производство, проведённые после включения настройки программы "Использовать производство в несколько этапов".

  • Для продукции, не использующей разделение на этапы, автоматически создаётся один предопределённый этап "Завершение производства".
  • При использовании многопередельного производства требуется предварительное формирование заказов на производство для всех вложенных сборок (полуфабрикатов).

Панель "Фильтры и настройки"

В правой части формы размещена скрываемая панель с двумя закладками:

  • Закладка "Фильтры"

    Содержит поля для наложения ограничений на список отображаемых заказов и продукции.

  • Закладка "Настройки"

    • Режим: Выбор между "Простой" и "Расширенный". В расширенном режиме доступно указание количества выпускаемой продукции для каждого этапа.
    • Формировать документы на дату: Поле для указания даты, на которую будут создаваться производственные документы.

Заполнение данных в этапах

Для массового заполнения реквизитов отмеченных этапов используйте подменю "Заполнить" в командной панели списка:

  • "Отметить этап выполненным" – открывает форму выбора этапа для его массовой отметки на всех позициях в списке.
  • "Заполнить изготовителя в отмеченных этапах" – открывает форму для выбора подразделения-изготовителя, которое будет подставлено во все отмеченные этапы.
  • "Заполнить исполнителя в отмеченных этапах" – открывает форму для выбора сотрудника или бригады, которые будут подставлены во все отмеченные этапы.

Важно:

  • Изготовитель может заполняться автоматически из данных заказа на производство. Если заказы на производство не используются — это поле следует заполнить вручную в соответствующих этапах.
  • Исполнитель указывается для этапов, требующих создания сдельных нарядов.

Формирование документов

После нажатия на кнопку "Выполнить этапы" будут сформированы документы по отмеченным этапам, а информация по отменённым этапам будет удалена.
