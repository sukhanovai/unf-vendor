Справочник "Маршруты согласования заявок"

Справочник "Маршруты согласования заявок" предназначен для создания маршрутов согласования для заявок на расход денег.

В справочнике заполняются следующие реквизиты:

  • Наименование. Указывается название маршрута.
  • Приоритет. Указывается приоритет маршрута. Приоритет маршрута должен быть уникален.
  • Участники маршрута. Указываются пользователи, которые должны будут последовательно рассмотреть и согласовать заявку. Список пользователей должен быть уникальным. Выбираются из справочника "Пользователи".

В маршруте, который используется в несогласованных заявках, нельзя редактировать таблицу участников. Приоритет при этом изменить можно. Также такой маршрут нельзя пометить на удаление.
